CE vs Point: Large Design-Space Experiments

Overview

This report runs a broad benchmark comparison between point-exchange (fedorov) and coordinate-exchange across:

  • trial_size: small, large
  • candidate_size: small, large
  • interaction complexity: none, some, many
  • quadratic complexity: none, some, many
  • nominal levels: 3, 4, 5
  • numeric density: low (-1:1 by 1) vs high (-1:1 by 0.1)

For each selected scenario, both methods are run with matched random seeds over multiple random iterations.

A power-driven meta-design is first generated using skpr to target:

  • alpha = 0.05
  • effectsize (SNR) = 0.5
  • power >= 0.95 for the method effect.

resolve_path <- function(candidates) {
  hit <- candidates[file.exists(candidates)]
  if (length(hit) == 0) {
    return(candidates[[1]])
  }
  hit[[1]]
}
