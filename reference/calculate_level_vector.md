# Calculate level vector

Calculate level vector

## Usage

``` r
calculate_level_vector(design, model, nointercept)
```

## Arguments

- design:

  Design to be analyzed.

- model:

  The model.

- nointercept:

  Whether an intercept is included.

## Value

A vector of levels.
